## ✨ Tính năng

- 🔊 **Phát âm TTS** — Web Speech API, không cần file audio
- 📱 **Responsive** — Học trên điện thoại, máy tính bảng, PC
- 📊 **Theo dõi tiến độ** — Tự động lưu bài đã học (localStorage)
